#Simple Python Calculator
A simple command-line interface (CLI) calculator built using basic Python concepts. This project performs fundamental arithmetic operations based on user input.

Features:
Addition (+): Adds two numbers.
Subtraction (-): Subtracts the second number from the first.
Multiplication (*): Multiplies two numbers.
Division (/): Divides the first number by the second.
Error Handling: Handles invalid operations and division by zero cleanly.

Concepts Used:
Variables and Data Types (int, str)
User Input Handling (input())
Conditional Statements (if, elif, else)
Functions & Operators
